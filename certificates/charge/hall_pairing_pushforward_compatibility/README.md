# Hall Pairing Pushforward Compatibility Certificate

This packet records finite algebraic degree compatibility for a supplied
bracket and supplied homogeneous pairing under the additive
normal-ordered Gram grading.

Run:

```
python3 compute/verify_hall_pairing_pushforward_compatibility_fixture.py --fixture certificates/charge/hall_pairing_pushforward_compatibility --check
```

Expected status:

```
HALL_PAIRING_PUSHFORWARD_COMPATIBILITY_VERIFIED
```

The packet does not construct compact Hall correspondences, prove
primitive closure, prove Hopf adjointness, prove Frobenius cyclicity,
prove quotient nondegeneracy, prove Pfaffian orientations, or prove
protected traces.
