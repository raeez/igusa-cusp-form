This packet verifies row 328: local divisor monodromy is irrelevant to
the Maass character nu_Delta5.

The proof is domain separation.  The Maass character is automorphic
target data on the type-II Weyl group and the chamber automorphism
group.  Local divisor monodromy is a meridian action on a compact Hall
local system over a punctured normal tube.  Without a supplied map from
the local meridian groupoid to the automorphic or Weyl group, no value
nu_Delta5(gamma_R_S_eta) is defined.

This packet does not construct local monodromy operators and does not
compute the row-329 simple wall orientations.
