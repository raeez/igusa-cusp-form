# rhomred_orientation_hall_product_descent

orientation descent through the \(E\)-quotient commutes with the Hall
product only after the quotient-orientation cocycle, the oriented
Thom--Sebastiani row, the external-product descent row, and the
compact-support pushforward comparison are supplied on the retained
extension correspondence.

comparison for already supplied operation rows.  It is not itself a
Joyce--Upmeier orientation row and does not populate the compact Hall
source product table.
