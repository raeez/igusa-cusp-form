This packet verifies row 326: no imaginary-divisor monodromy is being
called Weyl monodromy.

The Weyl character epsilon_o is a character of
W^(2)(Lambda_II^{2,1}), generated by real simple reflections
s_delta1, s_delta2, s_delta3.  Imaginary simple roots in the
Borcherds--Kac--Moody denominator algebra contribute multiplicity data
to the denominator product; they do not define Weyl reflection
generators.  Therefore a local monodromy around an imaginary divisor
component, if later constructed, is a separate datum and not a value of
epsilon_o.

Rows 327 and 328 handle the separate local divisor monodromy datum and
its irrelevance to the Maass character on W^(2).
