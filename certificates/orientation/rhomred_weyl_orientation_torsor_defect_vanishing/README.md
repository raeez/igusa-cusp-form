# Row 314 Weyl orientation torsor-defect vanishing

This packet records the finite criterion for proving row 314 of the
K3xE optimization ledger: all Weyl orientation torsor defects
omega_{i,R,S} vanish.

The packet is intentionally an obstruction packet.  It imports the row
313 torsor-defect computation packet, where the defect formula is
recorded but the torsor-defect vectors are not supplied.  Row 314
would require closed defect cochains, coordinates in fixed H1 bases,
zero-vector certificates, and complete retained-wall coverage for every
retained triple (i,R,S).

The present data do not prove the vanishing theorem.  They only verify
the criterion and the missing finite rows.
