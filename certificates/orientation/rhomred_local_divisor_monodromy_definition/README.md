This packet verifies row 327: local divisor monodromy is defined as a
separate source-side compact Hall datum.

A local divisor monodromy row consists of a retained compact Hall
divisor component, a punctured normal tube, a meridian, the restricted
oriented reduced coefficient system K_R = Phi_R^red tensor o_R, and
the meridian monodromy operator.  If a rank-one Pfaffian line is
supplied and preserved, its sign is a separate local sign.

The present packet records only the definition criterion.  It imports
the row-326 firewall and the obstruction ledgers for compact Hall
source data, reduced orientations, reduced vanishing-cycle transitions,
and finite Pfaffian data.  It does not construct divisor components,
normal tubes, meridians, local systems, Pfaffian-line summands, or
monodromy operators.
