This packet verifies row 329 as the chart-level orientation computation
criterion for the three simple type-II wall charts.

For each supplied rank-one chart over H_delta_i, the normal coordinate
u_i is reflected to -u_i and the tangent Pfaffian unit is invariant.
The local Pfaffian section upsilon_i u_i therefore changes by -1.  If
all three chart rows are supplied, the chart-orientation vector is
(-1,-1,-1).

The present packet records only the criterion and obstruction ledger.
The O2 wall-atlas and finite Pfaffian packets are empty blocked, so no
retained wall objects, chart rows, invariant units, quotient
orientations, or local sign rows are presently supplied.
