This packet records row 324: the semidirect-product extension decision
for the orientation character.

The abstract group-character statement is conditional and elementary.
If epsilon_o has been constructed on W^(2) and has value -1 on all
three type-II simple reflections, then the S3 chamber action preserves
epsilon_o because it only permutes those three generators.  Hence
epsilon_o extends to W^(2) semidirect S3.  There are exactly two
abstract extensions, according to the two characters of S3: trivial and
sign.  The Maass-compatible abstract extension is the trivial-S3
extension, because row 323 proves nu_Delta5 is trivial on S3.

This packet does not claim a compact-source orientation extension.
That requires semidirect Hall lifts of the chamber-permuting
reflections and compatible transport of the orientation line, square
root, quotient-orientation data, and semidirect relations.  Those are
the row-325 obligations.
