trivial on the type-I chamber automorphism group
Aut(Poly_II) ~= S3.

The proof is automorphic.  The three type-I reflections

- s_{f_-2-f_2},
- s_{f_2-f_3},
- s_{f_-2-f_3}

generate S3.  The imported Maass packet gives value +1 on each, hence
the character is trivial on S3.
